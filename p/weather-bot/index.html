02 / Про проєкт

Опис та призначення

Weather Scraper Bot автоматизує збір метеорологічних даних без потреби у платних ключах API. Бот напряму парсить показники з sinoptik.ua, відбираючи температуру, опис хмарності, швидкість та напрямок вітру.

Особливістю архітектури є поєднання aiogram v3, планувальника APScheduler та вбудованого мікросервера aiohttp. Веб-сервер відповідає на пінги зовнішніх систем моніторингу (UptimeRobot тощо), що дозволяє безкоштовно хостити бота на платформі Render без переходу в «сплячий режим».

Характеристики

  • ПлатформаTelegram + Render Cloud
  • ПарсингBeautifulSoup4 + lxml
  • Серверaiohttp (healthcheck)
  • ПланувальникAPScheduler
  • ЛіцензіяOpen Source · MIT

03 / Як працює

Принцип роботи

01

Асинхронний скрапінг

Бот завантажує актуальну сторінку прогнозу погоди та парсить блок метеоданих для міста.

02

Фільтрація та валідація

Очищення HTML-тегів, форматування температурних позначок та стрілок напрямку вітру.

03

Розсилка за розкладом

Планувальник завдань APScheduler генерує та надсилає красиве пуш-повідомлення щодня о 15:00.

04

Підтримка аптайму

Вбудований порт HTTP aiohttp слухає пінги сервера, забезпечуючи 99.9% доступності бота.

04 / Можливості

Ключові особливості

  • Повна автономність — робота без комерційних погодних API-ключів
  • Компактний та наочний формат повідомлень з емодзі
  • Точний прогноз температури, хмарності та вітрових поривів
  • Вбудований фоновий HTTP-сервер для Uptime-пінгів на хмарних хостингах
  • Чистий модульний Python-код із повною асинхронністю
  • Легке налаштування для будь-якого міста через змінні середовища
