02 · Про проєкт

Опис та призначення

Weather Scraper Bot збирає актуальний прогноз без використання платних метео-API. Скрипт напряму парсить сторінку sinoptik.ua, витягуючи температуру, стан хмарності, швидкість і напрямок вітру.

Архітектура поєднує aiogram 3, планувальник APScheduler та легкий HTTP-сервер на aiohttp, що відповідає на зовнішні перевірки аптайму для стабільної роботи на безкоштовних планах Render.

Характеристики

  • ПлатформаTelegram + Render
  • ПарсингBeautifulSoup4
  • Веб-серверaiohttp
  • ПланувальникAPScheduler
  • ЛіцензіяOpen Source · MIT

03 · Як працює

Принцип роботи

01

Асинхронний скрапінг

Завантаження актуальної сторінки прогнозу та розбір HTML-блоків метеоданих.

02

Форматування звіту

Очищення значень температури, опису погоди, швидкості та напрямку вітру в єдиний шаблон.

03

Розсилка за графіком

APScheduler щодня о 15:00 надсилає підготовлене повідомлення підписникам бота.

04

Healthcheck сервер

aiohttp обслуговує HTTP-запити моніторингу, щоб контейнер на Render не засинав.

04 · Можливості

Ключові особливості

  • Автономна робота без комерційних ключів до погодних API
  • Компактне зведення: температура, ясність неба, швидкість і напрямок вітру
  • Вбудований aiohttp endpoint для зовнішнього моніторингу аптайму
  • Модульний код на Python 3.10 із повною асинхронністю
  • Швидке переналаштування на інше місто через змінні середовища
