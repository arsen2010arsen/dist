02 / Про проєкт

Опис та призначення

Google Tasks Widget створений для тих, хто регулярно веде завдання в Google Екосистемі (Gmail, Google Calendar, Tasks), але не хоче постійно тримати окрему важку вкладку в Chrome або шукати потрібне вікно.

Завдяки платформі Tauri v2 та ядру на Rust, застосунок використовує нативний рушій відображення ОС, споживаючи лише близько 25–30 МБ оперативної пам'яті — це в 10 разів менше за типові Electron-додатки. Віджет ненав'язливо закріплюється на робочому столі, акуратно згортається в системний трей та підтримує гарячі клавіші.

Характеристики

  • ПлатформаWindows 10 / 11 (x64)
  • ЯдроRust + Tauri 2
  • Пам'ять~25 MB RAM
  • ЛіцензіяOpen Source · MIT
  • ТелеметріяНуль трекерів

03 / Як працює

Принцип роботи

01

1-Клік Google Авторизація

Безпечний вхід через офіційний OAuth 2.0 напряму в браузері. Токени зберігаються локально в захищеному сховищі.

02

Синхронізація списків

Віджет завантажує ваші списки справ через офіційний Google Tasks API та оновлює статус у режимі реального часу.

03

Керування в 1 клік

Створюйте нові завдання, призначайте дедлайни, додавайте в «Обрані» (зірочка) або завершуйте одним дотиком.

04

Робота у фоні та трей

Віджет ховається в системний трей Windows, не заважає роботі і миттєво відкривається при натисканні гарячої клавіші.

04 / Можливості

Ключові особливості

  • Ультранизьке споживання ресурсів (~25 МБ RAM проти 300+ МБ у веб-версії)
  • Підтримка фільтрації завдань: «Всі завдання» та «Зірочка» (Starred)
  • Перемикання між різними списками задач вашого Google-акаунту
  • Локальне кешування: завдання доступні для перегляду навіть без інтернету
  • Естетичний інтерфейс із темною темою та ефектом розмиття скла (Glassmorphism)
  • Інтеграція з системним треєм Windows та автозапуск при вході в систему
  • Повна приватність: софт спілкується виключно з серверами Google без проміжних бекендів
  • Відкритий вихідний код під вільною ліцензією MIT
