02 · Про проєкт

Опис та призначення

Google Tasks Widget створений для користувачів екосистеми Google, яким потрібно бачити актуальні списки справ на робочому столі, не тримаючи постійно відкриту вкладку браузера.

Завдяки платформі Tauri 2 та бекенду на Rust, віджет використовує нативний WebView2 операційної системи і споживає близько 25 МБ оперативної пам'яті. Програма згортається у системний трей Windows та відкривається за гарячою клавішею.

Характеристики

  • ПлатформаWindows 10 / 11 (x64)
  • ЯдроRust + Tauri 2
  • Пам'ять~25 MB RAM
  • ЛіцензіяOpen Source · MIT
  • ТелеметріяВідсутня

03 · Як працює

Принцип роботи

01

Авторизація Google OAuth

Безпечний вхід через офіційний OAuth 2.0 у браузері. Токени зберігаються локально на комп'ютері.

02

Синхронізація списків

Завантаження списків справ через Google Tasks API та оновлення статусів виконання.

03

Керування в один клік

Додавання нових завдань, призначення дат, додавання до обраних та відмітка завершення.

04

Робота з системного трею

Вікно ховається у трей Windows, не займає панель завдань та миттєво повертається при натисканні.

04 · Можливості

Ключові особливості

  • Низьке споживання пам'яті (~25 МБ RAM у фоні)
  • Перемикання між списками завдань та фільтром обраних
  • Створення, редагування, завершення та видалення завдань
  • Локальне кешування списків для читання без підключення до мережі
  • Системний трей Windows та підтримка автозапуску
  • Пряма взаємодія з Google API без проміжних серверів
